## 📖 **Overview**

**TechNova – Smart Shopping** is a web-based **E-Commerce application** developed using **HTML, CSS, and JavaScript** with practical implementation of **Data Structures and Algorithms (DSA)**.

The project combines an interactive shopping experience with concepts such as **Arrays, Searching, Sorting, Binary Search Tree, and Recommendation Algorithms**.

The main aim is to demonstrate how **DSA concepts** can be applied to solve real-world problems in an **E-Commerce system**.

---

## ✨ **Features**

- 🔍 **Product Search**
- 🔃 **Product Sorting**
- 🛒 **Shopping Cart Management**
- ❤️ **Wishlist Management**
- 📦 **Order Management**
- 💳 **Checkout System**
- 🌳 **Binary Search Tree for Price Searching**
- 🤖 **Product Recommendation System**
- 👨‍💼 **Admin Product Management**
- 💾 **LocalStorage Data Persistence**
- 📱 **Responsive User Interface**
